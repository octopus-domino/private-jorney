# Private Walks

Отдельный сервис для планирования приватных пеших прогулок.

## Стек

React 18 + TypeScript + Vite + Leaflet + OpenStreetMap
+ CoDoc `/api/journeys/buildings/*` и `/api/journeys/routes/places*` (все подборки интересных мест)
+ Overpass (только дорожный граф после записи прогулки)
+ CoDoc backend `/api/journeys/routes/road` (пешеходный маршрут)
+ Photon (геокодер, тот же, что проксирует бэк)

Полное описание версии 1.0.10: [назначение, сценарии, источники, архитектура, кеши и ограничения](docs/application-description.html).
Паспорт Петербурга сначала ищется по координатам самого городского портала; дом Москвы — по известному адресу или официальному контуру 60562.
Photon для этих успешных сценариев не требуется и остаётся запасным способом определения адреса.

## Запуск

    npm install
    python -m pip install -r dev/requirements.txt
    cp .env.example .env
    npm run dev

## Архитектура

Слоистая (domain → application → infrastructure → presentation).
Порты: `PoiRepository`, `HistoricalHouseRepository`, `MysticPlaceRepository`,
`RoutePlanner`, `Geocoder`, `DraftStore`.

Интеграция с CoDoc — единственный контракт `SharedWalk` из `src/shared/integration.ts`.
Кнопка «Включить в общий маршрут» передаёт `?walk=<base64url>` в основной продукт.

## Замена бэкенда

Достаточно реализовать нужный порт и подменить инстанс в `src/infrastructure/index.ts`.

## История маршрутов и карта

История хранится локально в прежнем ключе `private-walks/drafts/v1`: новые записи содержат выбранные и пользовательские точки, геометрию маршрута и непостроенные участки. Старые записи читаются без миграции. Ошибка обновления поиска не удаляет маршрут; ошибка записи в хранилище показывается пользователю.

Кластеры укрупнены. До максимального масштаба нажатие приближает группу; на максимальном — открывает прокручиваемый список всех её точек, включая совпадающие координаты. После построения маршрута остальные точки скрыты до нажатия отдельной кнопки.

## Дополнительные сведения о доме

Вкладки карточки разделяют историю места и понятную сводку о доме. Источники подключены через отдельные порты; получение данных, разбор HTML/JSON и правила интерпретации отделены от React.

* Citywalls: сетка и GeoJSON карты `map_around.html`, сопоставление по координатам, фрагмент статьи и прямая ссылка. Неоднозначные совпадения не показываются.
* «Наш Санкт-Петербург»: точный поиск дома с проверкой координат, технический паспорт, программа ремонтов, агрегированная возрастная таблица. Нулевые значения и служебные сведения не выводятся. Материалы и детали интерьера показываются только при подтверждении в данных; дощатые полы не трактуются как деревянные лестницы, а наличие плитки не подтверждает её исторический возраст.
* Циан: `mobile-search-frontend/v1/get-results-for-map-microfrontend/`, JSON из manifest разбирается без выполнения удалённого JavaScript. Avito: `/js/1/map/items`, контракт проверен по предоставленному пользователем ответу. Карточки содержат фото, цену и ссылку. Аренда, нулевые цены, соседние дома и снятые объявления отбрасываются. Доступ к Avito из среды разработки ограничен по IP; ошибка одного источника не скрывает другой.

Словесная интерпретация износа и потребности в капремонте использует СП 547.1325800.2025, п. 6.1, с округлением по п. 6.5: до 30%, 31–50%, 51–65%, выше 65%. Газ и лифты исключены согласно п. 1.2. Это интерпретация опубликованного паспорта, без нового обследования и присвоения дому категории безопасности. Проценты и даты находятся в раскрываемых подробностях. Даты ремонта не используются для вывода о его необходимости. Условные подписи численности жителей явно отделены от нормативных порогов.

[Официальная карточка СП в Росстандарте](https://protect.gost.ru/sp/details/788ebe69-0a3e-4e3b-a965-f7dbf5b8dad2), [официальное издание на сайте разработчика МГСУ](https://mgsu.ru/news/2025/23-10-2025-SP-547.pdf).

## Веб и Android

У приложения нет отдельного бэкенда. Для локальной разработки `npm run dev` включает вспомогательный Vite-прокси `/history-source`, код которого находится в `dev/`. Python нужен только компьютеру разработчика; в APK он не включается.

В Android зарегистрирован локальный плагин `PublicSources`: он выполняет публичные GET-запросы в отдельном Chromium WebView с HTTPS-origin источника, а не `https://localhost` основного приложения. Загружается только собственный пустой документ, удалённый HTML не выполняется как код. Есть список разрешённых URL, очередь, отмена и таймаут. Внешний сервер, Nginx и настройки прокси для APK не нужны. Системные сертификаты проверяются; защита TLS и CORS основного приложения не отключается. Ограничения доступа самого источника обрабатываются как ошибка, а не отсутствие объявлений.

В статической веб-сборке запросы идут непосредственно к источникам и зависят от их CORS; локальный режим разработки использует Vite-прокси. Это ограничение браузера не переносится на Android-транспорт.

Карточка обычного нажатия на здание содержит те же вкладки «О месте»/«О доме», что карточка POI. Доступны история и фото Citywalls, паспорт и объявления без добавления дома в маршрут. Citywalls показывает до двух полных абзацев без прежнего обрезания до 500 символов.

После изменений: `npm run build`, `npx cap sync android`, затем сборка Gradle. Карточка адаптирована для узкого экрана и альбомной ориентации: заголовок, вкладки и действия остаются доступными при прокрутке содержимого.

## Проверки

### Обновление 1.0.2

Все панели, карточки, группы точек и модальные окна закрываются свайпом вниз.
Прокрутка содержимого и отменённый системный жест не закрывают окно. Обе кнопки
геолокации каждый раз центрируют карту, повторный запрос не создаёт дубль точки.

Группы открывают полный список своих уникальных мест одним нажатием на любом
масштабе. При приближении области уменьшаются; отключена анимация старых кластеров,
которая затрудняла проверку их состава после обновления точек.

Звёздочка в карточках сохраняет место в локальное избранное независимо от маршрута.
Кнопка ★ в шапке открывает список с фильтром по городу, удалением и переходом к месту.
В истории маршрутов отображаются город и выбранные точки «от / до».

Citywalls сохраняется в локальном кэше на семь дней, паспорта домов — на сутки,
не более 60 записей каждого источника. Сохраняются разобранные успешные данные,
проверяемые при восстановлении; ошибки и пустые ответы не записываются. Сведения
сохраняются при перезапуске приложения. Для паспорта видна исходная дата получения.
Avito не кэшируется. Циан хранит успешную выдачу по bbox на 10 минут, до 12 областей;
при открытии дома сначала проверяются найденные в этих областях объявления.
Сохраняются только поля карточек, без телефонов, авторов и токенов. Ошибки/CAPTCHA
не кэшируются. Локальный Vite-посредник выдачу недвижимости не сохраняет.

Для Москвы подключён «Узнай Москву»: публичный `/api/v2/points?filter[type]=house`
и структурированный JSON страницы здания. Проверяются координаты, адрес и slug;
чужой соседний дом не подставляется. Индекс хранится сутки, история — семь дней.
HTML/скрипты источника не исполняются при разборе. Это исторические сведения,
а не технический паспорт с износом и коммуникациями.

Циан использует два механизма: прежний GET с manifest и POST
`search-engine/v1/search-offers-mobile-site/` с предоставленным пользователем
контрактом `path/subdomain`. Обновление области после остановки карты отложено
на 600 мс; поиск конкретного дома сохраняет проверку адреса и координат.
HTTP 403/CAPTCHA показываются как ограничение доступа, а не отсутствие квартир.

Подписчики общего геокодирования отменяются независимо друг от друга. Закрытая
карточка не оставляет отменённую загрузку следующей карточке; локальный Vite
останавливает дочернюю загрузку, когда у неё нет читателей. Добавлен один повтор
временных сетевых/серверных ошибок, обновление истёкшей сессии Citywalls и повторный
поиск паспорта по геокодированному адресу. Необязательная программа ремонтов имеет
отдельный таймаут и не блокирует уже доступный технический паспорт.

### Исправление городского портала в Android (1.0.1)

Городской портал перенаправляет запросы с мобильным User-Agent на `/m/`, включая
JSON-поиск и страницы технического паспорта. Только для `gorod.gov.spb.ru` плагин
`PublicSources` запрашивает десктопное представление, сохраняя версию Chromium
установленного WebView. Citywalls и другие источники сохраняют прежний User-Agent.
В запросах поиска сокращения корпуса (`19к2`, `19 к2`) раскрываются в `19, корпус 2`.
Совпадение дома по координатам по-прежнему обязательно. Проверка Android-правила:
`android/gradlew.bat -p android :app:testDebugUnitTest`.

`npm test` — регрессионные проверки истории, реальных обезличенных ответов источников, нормативных границ и скрытия нулей.

`npx playwright install chromium`, затем `npm run test:e2e` — карта, восстановление маршрута, карточка и независимость источников на desktop, Pixel 5, маленьком экране и в альбомной ориентации. Тесты используют сохранённые ответы и не зависят от доступности внешних сайтов.
