# Восстановление загрузки codoc.site (1.0.6)

После сообщения о регрессии разобрана сохранённая APK 1.0.2. Она использует прямой fetch к
https://www.codoc.site, limit=200 для домов и не отменяет запрос принудительно через двадцать секунд.
В последующих изменениях лимит был увеличен до 500, введена отмена через 20 секунд и затем заменён
сам транспорт. Замена транспорта не устранила пользовательскую ошибку.

В 1.0.6 восстановлены fetch и параметры рабочей версии. Экспериментальный CodocHttp-плагин удалён.
Краткие изменения фильтров снова объединяются задержкой 400 мс; устаревший поиск отменяется сразу.
Предыдущая невыбранная выдача очищается сразу, но новый запрос стартует после стабилизации фильтра.
Успешные ответы каждой категории показываются независимо. Принудительный предел для зависшего
поиска увеличен до 90 секунд, чтобы не отменять обычный холодный ответ сервиса через 20 секунд.
Поиск вокруг всех выбранных опорных точек сохранён.

Тесты сверяют параметры, заголовки, источник и транспорт с рабочей APK; отдельно проверяют ответ,
приходящий после двадцатой секунды. Проверка браузерного профиля Pixel 5 не считается проверкой APK на телефоне.

Реальная проверка из origin `https://localhost` с Android WebView User-Agent получила HTTP 200 и 200 домов
через 29,012 секунды. Запрос с прежним двадцатисекундным ограничением обрывался бы до этого ответа.
То же время ожидания codoc применяется к дополнению записанной прогулки: прежний отдельный лимит
18 секунд также отменял бы такой ответ.
