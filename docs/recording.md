# Запись прогулки (1.0.3)

[Привязка GPS к пешеходному графу и таймлайн участков](recorded-walk-map-matching.md)

На главной странице доступны карта, запись и руководство. Запись запускается только кнопкой пользователя.
Избранное осталось в прежнем интерфейсе. В сохранённых планах длинные названия переносятся.
Выбранный адрес закрывает мобильную панель и центрирует карту; поиск охватывает все точки области.

## Android

`WalkRecorderPlugin` управляет `WalkRecordingService` — foreground location service с уведомлением и кнопкой остановки.
Требуется точное местоположение; уведомления запрашиваются на Android 13+. Дополнительный backend не нужен.
Сервис не запрашивает сведения о домах и не удерживает экран включённым.
Интервал запроса координат — 12 секунд, минимальное перемещение — 12 метров, допустимая пакетная задержка — 30 секунд.
Фильтр отбрасывает погрешность свыше 45 метров, устаревшие измерения, шум и скачки скорости.
Фактическая частота зависит от Android и провайдера координат.
В 1.0.4 запись предпочитает GNSS-провайдер с высокой точностью: экономичный fused-режим мог выдавать только
приблизительные координаты, которые отбрасывал фильтр. Стартовая точка дополнительно запрашивается один раз
тем же механизмом, что и булавка карты, и передаётся нативному сервису. Второй постоянный watcher не создаётся.

Журнал `.ndjson` и атомарная метаинформация хранятся в `noBackupFilesDir`.
Первая точка сбрасывается сразу, следующие — пакетами примерно раз в 30 секунд и при остановке.
При резком завершении процесса может потеряться последний несброшенный пакет; уже записанная часть восстанавливается.
Автоматического удаления старых прогулок нет. Удаление выполняет пользователь.
Резервное копирование Android отключено для приложения: GPS-записи предназначены для локального хранения.

## Путь и рассказ

Сначала журнал сохраняется в IndexedDB вместе с автономной SVG-схемой. Ошибка сети не отменяет этот этап.
После остановки строится локальный пешеходный граф из OSM: общие node id сохраняют топологию мостов и пересечений.
Ограниченный Дейкстра оценивает переходы; Витерби выбирает последовательность проекций GPS на рёбра.
Исходные GPS-точки сохраняются независимо от сопоставленной геометрии. Отсутствие графа не удаляет путь.
Пространственная сетка ограничивает число кандидатов; временная последовательность сохраняет петли и возвращения.
Обработка ограничена 600 наблюдениями, 200 координатами коридора, пакетами по 50 координат и шестью областями поиска.
Длинные прогулки с неполным покрытием отмечаются как частично дополненные, можно повторить дополнение.

В истории путь делится по подтверждённым перекрёсткам и поворотам. На каждом участке
кружки показывают расстояние от его начала, а карточки домов располагаются слева или
справа по ходу движения. Короткие подписи и фотографии берутся из доступных источников
мест. Старую запись можно обработать заново кнопкой «Обновить путь и рассказ».
Подробности сопоставления GPS с уличным графом приведены в [описании алгоритма](recorded-walk-map-matching.md).

Все точки интереса, включая дома, берутся исключительно с codoc.site, для всех выбранных опорных точек.
При изменении категории прежняя невыбранная выдача очищается сразу. Поиск ограничен 90 секундами,
успешные категории показываются по мере готовности; поздние ответы старого фильтра игнорируются.
Overpass используется только для геометрии пешеходного графа после записи:
[around вдоль полилинии](https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_QL#Around_(around)).
Успешные дорожные коридоры кэшируются на сутки, ошибки не кэшируются.
Граф, название города и поиск мест загружаются независимо. Отчёт появляется сразу, а
места добавляются по мере ответов. История максимум 12 мест загружается
последовательно в пределах общего бюджета, используя существующий кэш Citywalls/«Узнай Москву».
Сторона определяется направлением движения; при большой погрешности подписывается «рядом».
Рассказ формируется локально из фактов и сохранённых фрагментов источников, без выдуманных событий.
Схема, путь и текст доступны без сети. Фотографии по внешним URL могут требовать интернет.

В браузере запись работает только в открытой вкладке; фоновые гарантии относится к Android-сервису.
При скрытой странице JavaScript не опрашивает статистику. Без активной записи периодический опрос отключён.

## Проверка

`npm test`, `npm run test:e2e -- --workers=2`, `npm run build`.
`android/gradlew.bat -p android :app:testDebugUnitTest :app:assembleDebug` после `npx cap sync android`.
UI проверяется на desktop, Pixel 5, 360×640 и 740×360 с контролируемыми ответами внешних источников.
Фактический расход батареи, выключенный экран и ограничения конкретного производителя требуют проверки на телефоне.
Подключённого Android-устройства во время разработки не было.
